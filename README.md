# Smart Inventory & Expiry Tracker (C++)

A console-based inventory management application written in C++ designed to streamline stock tracking, generate low-stock warnings, and flag expired products for small retail businesses.

## Key Features

- **Item Management:** Add, view, and monitor product inventories with dynamic pricing and expiration data.
- **Automated Alerts:** Filter items triggering low-stock thresholds or past their expiration dates.
- **Data Persistence:** Automatically saves and loads records using C++ File I/O (`fstream`).
- **Object-Oriented Design:** Modular design utilizing class abstraction, encapsulation, and C++ STL (`std::vector`).

## Tech Stack

- **Language:** C++ (C++11 or higher)
- **Concepts:** Object-Oriented Programming (OOP), STL Containers, File Streams (`fstream`)
